# Core Stack
- **Language**: TypeScript 6.0
- **Frontend Framework**: React 19 + Vite 8.2
- **Styling**: Tailwind CSS 4.3 + Custom Glassmorphism CSS System

# Animation & Video Engine
- **Canvas Rendering Engine**: Canvas2D API with scaling resolution math
- **Video Encoder**: Browser WebCodecs API (`VideoEncoder`, `VideoFrame`) with dynamic `isConfigSupported()` capability discovery (`avc1.4d402a`, `avc1.640033`, `vp09`)
- **MP4 Container Muxer**: `mp4-muxer` (ArrayBufferTarget)

# UI & Utilities
- **Icons**: Lucide React
- **Celebration FX**: `canvas-confetti`
- **Linter & Quality**: Oxlint 1.75 + TypeScript (`tsc -b`)
